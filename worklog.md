# SentraRMM — Worklog (shared handover document)

Project: **SentraRMM** — a legitimate, open-source-ready Remote Management & Monitoring (RMM) web dashboard for the user's own Windows machines (work/home), designed for red/blue team security assessments. Liquid-glass UI, light/dark mode.

## Architecture (agreed contract)

- **Next.js 16 App Router** on port 3000 — the ONLY user-visible route is `/` (SPA-style dashboard with client-side view switching).
- **API routes** under `src/app/api/**` (NO server actions). Shape: `{ ok: true, data } | { ok: false, error }`.
- **Prisma + SQLite** (`prisma/schema.prisma`, db file in `db/`). Schema is PUSHED already (Device, CommandExecution, MediaAsset, NetworkCapture, LocationPing, FileOperation, ProcessSnapshot, Alert, AuditLog, Setting, SavedCommand).
- **Realtime hub**: mini-service at `mini-services/agent-hub` (bun + socket.io + express-like HTTP, port **3003**). Path must be `/`. Browser connects via `io("/?XTransformPort=3003", { path: "/" })`.
- **Simulated Windows agents** run inside the hub (3 fake devices: work laptop, home PC, lab server) so every feature is demo-able end-to-end in the sandbox. Real agents would connect with the same socket protocol.
- **Shared types/contract**: `src/lib/types.ts` — READ THIS FIRST. Defines all entities, every API route, and every socket event.
- **Design system**: `src/app/globals.css` — liquid glass utilities: `.glass`, `.glass-strong`, `.glass-inset`, `.glass-hover`, `.mesh-bg`, `.status-dot` (+ `--static`), `.terminal-glass`, `.scroll-slim`, `.text-gradient`. Accent = emerald/teal (oklch hue ~165-190). NO blue/indigo. Use `bg-primary text-primary-foreground` for primary buttons.
- shadcn/ui New York components in `src/components/ui/**` — USE THEM, don't rebuild.
- recharts available for charts. leaflet/react-leaflet NOT installed yet (Task 3-c installs it).
- Footer must be sticky (min-h-screen flex flex-col + mt-auto).
- Theme: next-themes with class strategy (`suppressHydrationWarning` already in layout).

## API contract summary

See `src/lib/types.ts` (single source of truth). Backend implements exactly those routes; frontend consumes them via `api<T>()` helper from the same file.
