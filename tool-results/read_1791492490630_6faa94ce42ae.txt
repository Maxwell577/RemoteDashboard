     3→Project: **SentraRMM** — a legitimate, open-source-ready Remote Management & Monitoring (RMM) web dashboard for the user's own Windows machines (work/home), designed for red/blue team security assessments. Liquid-glass UI, light/dark mode.
     4→
     5→## Architecture (agreed contract)
     6→
     7→- **Next.js 16 App Router** on port 3000 — the ONLY user-visible route is `/` (SPA-style dashboard with client-side view switching).
     8→- **API routes** under `src/app/api/**` (NO server actions). Shape: `{ ok: true, data } | { ok: false, error }`.
     9→- **Prisma + SQLite** (`prisma/schema.prisma`, db file in `db/`). Schema is PUSHED already (Device, CommandExecution, MediaAsset, NetworkCapture, LocationPing, FileOperation, ProcessSnapshot, Alert, AuditLog, Setting, SavedCommand).
    10→- **Realtime hub**: mini-service at `mini-services/agent-hub` (bun + socket.io + express-like HTTP, port **3003**). Path must be `/`. Browser connects via `io("/?XTransformPort=3003", { path: "/" })`.
    11→- **Simulated Windows agents** run inside the hub (3 fake devices: work laptop, home PC, lab server) so every feature is demo-able end-to-end in the sandbox. Real agents would connect with the same socket protocol.
    12→- **Shared types/contract**: `src/lib/types.ts` — READ THIS FIRST. Defines all entities, every API route, and every socket event.
    13→- **Design system**: `src/app/globals.css` — liquid glass utilities: `.glass`, `.glass-strong`, `.glass-inset`, `.glass-hover`, `.mesh-bg`, `.status-dot` (+ `--static`), `.terminal-glass`, `.scroll-slim`, `.text-gradient`. Accent = emerald/teal (oklch hue ~165-190). NO blue/indigo. Use `bg-primary text-primary-foreground` for primary buttons.
    14→- shadcn/ui New York components in `src/components/ui/**` — USE THEM, don't rebuild.
    15→- recharts available for charts. leaflet/react-leaflet NOT installed yet (Task 3-c installs it).
    16→- Footer must be sticky (min-h-screen flex flex-col + mt-auto).
    17→- Theme: next-themes with class strategy (`suppressHydrationWarning` already in layout).
